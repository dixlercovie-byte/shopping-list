# Quick Notes

A Manifest V3 extension (Chrome/Edge; Firefox 128+ with minor tweaks) for quick notes.

- Write notes in the popup, optionally attached to the current page
- Right-click selected text → "Save selection to Quick Notes"
- Search, edit, and delete notes (stored locally with `chrome.storage.local`)
- Ctrl/Cmd+Enter saves

## Install
1. Open `chrome://extensions` and enable Developer mode
2. Click "Load unpacked" and choose this `notes-extension` folder
